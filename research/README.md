# Feature design

[feature-matrix.json](feature-matrix.json) records general feature requirements and implementation status. It contains no personal machine inventory or test-run data.

The [REA workflow](https://github.com/morluto/rea) informed the independent implementation. Detailed comparison evidence and local validation artifacts remain private and are excluded from version control. Observing an interface does not establish its security effectiveness.
